# Thingport on Railway

Thingport — a self-hosted 3D-print model library and importer. Deploy on Railway with one click.

This repository packages the official [Thingport](https://github.com/TautvydasDerzinskas/Thingport) images (`thingport-backend` / `thingport-frontend` 1.5.0, AGPL-3.0) and FlareSolverr v3.5.2 (MIT) for Railway. Independent community packaging, not affiliated with the Thingport project.
